HACKATHON ARCHITECTURE & SPECIFICATION

Disaster-Resilient Emergency Network — Project Flow

01

Problem Statement & Core Hackathon Objectives

In major disasters (earthquakes, cyclones, floods), central cellular towers and terrestrial fiber grids are knocked out within the first minutes. First responders are left blind and isolated.

Autonomous Mesh Topology Deployable ad-hoc nodes (Rescue squads, ambulances, air drones, command HQ) that discover and route through each other without Internet.
Dynamic Self-Healing When an intermediate node is destroyed or link severed, the network dynamically detects the topology change and self-repairs in <10ms.
Dijkstra Shortest Route Computes optimal hop-by-hop forwarding using latency, link signal strength, and remaining battery reserves as cost metrics.
Priority Dispatch Engine Critical life-saving SOS packets are guaranteed delivery with route tracing and verification.
02

End-to-End System Execution Flow

Phase 1

Node Deployment & Discovery

Field units (A, B, C, D, E, F) broadcast beacon frames over ISM RF band (LoRa/Wi-Fi ad-hoc). Each node establishes neighbor links and measures ping latency & RSSI.

Phase 2

Graph Weight Construction

Adjacency matrix weights $W(u, v)$ are populated using composite metrics: physical latency + signal degradation penalty + battery deficiency penalty.

Phase 3

Dijkstra Shortest Path Execution

When an emergency message is dispatched from Node A to Command F, Dijkstra's algorithm relaxes edges to identify the lowest cost multi-hop path.

Phase 4

Fault Detection & Self-Healing Loop

If an intermediate node goes offline, neighbor heartbeats fail. The node is marked down, its edges pruned, and Dijkstra instantly reroutes over healthy secondary relays.

Phase 5

Operator Command Telemetry

Web dashboard receives sub-second topology snapshots via WebSockets, allowing central commanders to inspect link health and dispatch life-safety aid.

03

Dijkstra Algorithm Mathematical Formulation

Cost(u, v) = Latency_{uv} + \alpha \cdot (100 - Signal_{uv}) + \beta \cdot (100 - Battery_v) + P_{degraded}

Unlike naive shortest-path algorithms that only count hop counts, this disaster-resilient metric penalizes links with poor signal-to-noise ratios or dying battery reserves, ensuring critical SOS packets are never dropped mid-route.

04

Physical Deployment & Hardware Stack

Microcontroller Relays ESP32-S3 with SX1262 LoRa transceivers (868MHz / 915MHz) operating up to 15km line-of-sight.
Autonomous Aerial Relay Tethered or roaming DJI/Pixhawk drone (Node C) carrying an RF mesh relay to bridge mountainous or flooded terrain.
Field Power System 18650 LiFePO4 battery pack with 20W fold-out solar charging panels for indefinite off-grid deployment.
First Responder UI Progressive Web App (PWA) running locally on responder rugged tablets connecting to local node Wi-Fi AP.
